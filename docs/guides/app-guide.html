HookFeed app guide

Version 0.2.0 · macOS 14 or later · 24 October 2026

HookFeed brings updates from local agents and scripts into one native Mac inbox. Notice completed work, failures, and requests for input, then return to the relevant project or terminal session. Messages stay in local SQLite storage. No account, API key, or model inference is required.

Get started

Open HookFeed, review the welcome checklist, and choose Open Inbox. In Settings → Integrations, send a test message and copy your tool’s configuration. Use the supplied command to put the bundled CLI on your PATH. Then send an update:

hookfeed send "Build complete" \
  --project MyProject --kind completed

Read and organize

Use Needs attention, Unread, All, project, or source filters. Search titles, bodies, projects, and sources within the active filter. Related updates share a thread, newest first. Opening a thread marks its updates read; unread failures and attention requests drive the attention count. Use Mark unread or Mark all read to manage the queue.

Return to work and connect tools

Thread details can open an existing folder in your editor, reveal it in Finder, copy a supported agent resume command, or open a source link. Run copied commands in your terminal. Claude Code hooks report completions and selected input or permission requests; Codex hooks report completions. MCP sends depend on the agent calling the tool. Scripts use hookfeed send or hookfeed run. Choose one delivery route per agent to avoid duplicates.

Settings and local data

General controls notifications, badge counts, and the editor. Defaults are all-update notifications, sound off, and an attention-only badge. Enable notification permission explicitly; macOS settings and Focus govern delivery. Banners show title and source; bodies remain in the inbox. Storage shows counts and the database location. Sends persist while the app is closed. The menu bar offers a compact inbox. Thread deletion is permanent after confirmation.

Default database: ~/Library/Application Support/HookFeed/inbox.sqlite
